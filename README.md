This repo is specifically to hold and create cards for Mochi containing the Vulgate text with
the Douay-Rheims (unfortunatly Challoner's) English. 

The cards are in CSV according to the Mochi docs.[https://mochi.cards/docs/import-and-export/importing/]

Example:
```
"Front";"Back"
"<p>_ Psalm 116:2 _<br><br>Quoniam confirmata est super nos misericordia ejus, et veritas Domini manet in æternum.</p>";"<p>For his mercy is confirmed upon us: and the truth of the Lord remaineth for ever.</p>"
"<p>_ Psalm 116:1 _</p><br><p>Laudate Dominum, omnes gentes; laudate eum, omnes populi.</p>";"<p>O praise the Lord, all ye nations: praise him, all ye people.</p>"

```
